# Gemma 4 — 핵심 스펙 (해커톤용)

**Fetch 일자**: 2026-05-06
**출처**: ai.google.dev 모델카드, HuggingFace blog/gemma4, deepmind.google, news.hada.io 한글 요약

## 변종 4종

| 변종 | Effective | Total | RAM | 컨텍스트 | 입력 모달리티 | 출력 |
|---|---|---|---|---|---|---|
| **E2B** | 2.3B | 5.1B | ~2GB | 128K | text + image + **audio** | text |
| **E4B** | 4.5B | 8.0B | ~4GB | 128K | text + image + **audio** | text |
| **26B A4B** (MoE) | — | 26B | 서버 | 256K | text + image | text |
| **31B Dense** | — | 31B | 서버 | 256K | text + image | text |

**라이센스**: Apache 2.0 (모든 변종, 상용 OK)
**출시**: 2026-04-02

## 폰 운용 (E2B/E4B)

- ✅ **완전 오프라인** 가능 ("can run entirely offline")
- ✅ Google AI Edge Gallery 앱으로 Android/iOS 즉시 체험 가능
- ✅ ASR + speech-to-translated-text 빌트인 (E2B/E4B)
- ✅ Function calling 네이티브
- ✅ 양자화: GGUF Q4_K_M (llama.cpp), MLX TurboQuant 4× 메모리 절감

**모바일 추론 SDK**:
- llama.cpp (Metal/CUDA, GGUF) — 가장 성숙
- ONNX Runtime — 안드로이드 NPU 가능
- MLX — Apple Silicon (iPhone/iPad)
- transformers.js — WebGPU 브라우저
- LiteRT-LM — Google 자체 모바일 런타임 (hada 글 언급)
- ⚠️ MediaPipe LLM Inference API 명시적 지원 여부는 공식 문서에 없음 (확인 필요)

## 언어 지원

- **즉시 사용 (out-of-the-box)**: 35+ 언어
- **사전학습**: 140+ 언어
- **명시적 언급**: 영어, 스페인어, 프랑스어, 독일어, 일본어, **한국어**, 중국어, 포르투갈어, 이탈리아어, 힌디어 등
- **러시아어**: 사전학습 포함된 듯하나 35+ "즉시 사용" 목록 명시는 안 보임 → **품질 테스트 필수**
- ⚠️ **경고**: Gemma 3n 모바일 변종에서 영어→스페인어/러시아어 전환 시 성능 저하 보고됨 ([HF 사용자 관찰](https://huggingface.co/google/gemma-2-9b/discussions/33)). Gemma 4 E2B/E4B 도 동일 가능성 있음.

## 멀티모달 세부

| 기능 | 지원? |
|---|---|
| 텍스트 in | ✅ 모든 변종 |
| 이미지 in (정지) | ✅ 모든 변종, 가변 해상도 |
| 비디오 in | ✅ 모든 변종 (네이티브) |
| 오디오 in | ✅ E2B/E4B 만 (음성 인식+번역) |
| 텍스트 out | ✅ |
| 음성 out (TTS) | ❌ — OS TTS / ElevenLabs / Cartesia 별도 |
| 이미지 out | ❌ — SD Turbo / 디퓨전 별도 (필요시) |

## 안전 / 어린이 앱 관련

- 모델 카드: CSAM, 자살 권유, 위험 행위 등 안전 평가 통과
- "Developers should implement appropriate content safety safeguards based on their specific product policies"
- → **0-8세 대상 앱**은 자체 콘텐츠 필터 + 부모 검토 모드 필수

## 우리 프로젝트에 직결되는 시사점

1. **E2B = 폰 단독 메인 데모 가능**: 음성 입력 + 이미지 입력 + Function calling 다 됨
2. **러시아어 품질 미검증** = 1번 리스크 → 즉시 테스트
3. **음성 출력은 OS TTS 무료 옵션** + 프리미엄에서 클론 보이스
4. **Apache 2.0** = 세종 사업화 + 본 해커톤 동시 합법
5. **이미지 생성 불필요** → 디퓨전 빼도 됨 (학습 앱은 사전 일러스트+웹툰으로 충분)
6. **moon1 의 26B 모드** = 라이브 아바타 결합용 프리미엄 사이드카
