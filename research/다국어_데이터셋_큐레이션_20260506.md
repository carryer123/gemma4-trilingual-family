# 다국어 파인튜닝 데이터셋 큐레이션 계획

**일자**: 2026-05-06 (업데이트: 가정 trilingual 확정 — KO+RU+EN)
**스코프**: **Trilingual core (KO/RU/EN)** + 일반화용 추가 언어쌍

## 트리링구얼 코어 (메인 학습 + 데모)

| 페어 | 건수 | 이유 |
|---|---|---|
| KO ↔ RU | 8,500 | 와이프-남편/아이 양방향 |
| KO ↔ EN | 5,000 | 본인-와이프 브릿지 언어로서 KO 설명, 일반화 |
| RU ↔ EN | 5,000 | 부부 평소 대화 → 학습화 |
| **3-way trilingual triple** | **2,000** | 한 사물 → KO+RU+EN 세트 + 교차 설명 |

**브릿지 언어 데이터** (NEW): 와이프가 "KO 격조사 '에' vs '에서' 차이를 EN 으로 설명해줘" 같은 요청 → KO+EN 페어에 system prompt 로 "explain Korean grammar in English" 라벨링.

## 합성 데이터 (26B distill, 드래프터로 3× 가속)

**프롬프트 템플릿 (3언어 사물 카드 — trilingual)**:
```
[SYSTEM] 너는 trilingual 다문화가정 (KO+RU+EN) 부모-자녀 공동학습 AI다.
사용자가 사물 이름을 주면, 가족 전원용 학습 카드를 다음 JSON 으로 응답한다:
{
  "word": {"ko": "...", "ru": "...", "en": "..."},
  "phonetic": {
    "ko_in_cyrillic_for_ru": "...",
    "ru_in_hangul_for_ko": "...",
    "ko_in_latin_for_en": "...",
    "ru_in_latin_for_en": "..."
  },
  "wife_card": {
    "target": "ko",
    "explanation_in": "ru | en",   // 와이프가 어느 브릿지 선택했는지
    "text": "..."
  },
  "husband_card": {
    "target": "ru",
    "explanation_in": "ko | en",
    "text": "..."
  },
  "child_card": {
    "ko_simple": "...", "ru_simple": "...", "en_simple": "...",
    "audio_focus": "발음 반복용 짧은 문장 3종"
  },
  "l1_contrast": {
    "ko_vs_ru": "한·러 음운/문법 차이",
    "ko_vs_en": "한·영 차이",
    "ru_vs_en": "러·영 차이"
  }
}

[USER] 사과
[ASSISTANT] {...}
```

이걸 1.5K 사물에 대해 26B 가 생성 → 와이프가 100건 검수 → 통과율 따라 전체 채택/재생성.

**프롬프트 템플릿 (가족 시나리오)**:
- 식사, 산책, 목욕, 잠자리, 마트, 병원, 공원 등 가정 일상 50개 시나리오
- 시나리오당 30건 변형 = 1.5K
- 변형 축: 아기 나이 (0-2/2-4/4-6/6-8), 부모 한국어 수준 (초/중/고)

**프롬프트 템플릿 (함수콜 라벨)**:
- 발음점수 입력→출력 200건
- 미션 추천 200건
- L1 설명 호출 100건
- 연령 모드 전환 100건

## 평가 셋

- **Flores-200 KO↔RU** 1,000건 (자동 BLEU/COMET)
- **자체 가족 시나리오** 100건 (와이프 + 본인 채점, 5점 척도)
- **함수콜 정확도** held-out 100건 (스키마 일치율)

## 데이터 거버넌스

- 와이프/아기 음성 데이터 = 본인 가족 자체 수집, 외부 공개 X
- GitHub repo 공개 시 합성 데이터만 (Apache 2.0 호환)
- 안전 거부 데이터 500건은 OWASP LLM 가이드라인 + 어린이 콘텐츠 보호 기준
