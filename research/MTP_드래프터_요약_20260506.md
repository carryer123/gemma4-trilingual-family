# Gemma 4 MTP (Multi-Token Prediction) 드래프터 — 요약

**Fetch 일자**: 2026-05-06

## 핵심

- Speculative decoding 의 **드래프트 모델만 사전 학습된 76M 파라미터 짜리** 를 Google 이 별도 공개
- **3× 추론 가속**, 품질/추론 로직 무손실
- 라이센스: Apache 2.0 (가정 동일)

## 작동 원리

1. **드래프터 (76M)** 가 다음 N개 토큰 후보를 한번에 예측
2. **타겟 모델** (E2B/E4B/26B/31B) 이 single forward pass 로 검증
3. 일치 → 한 forward 로 N+1 토큰 생성, 불일치 → 그 지점부터 타겟이 직접 1토큰 생성
4. **KV 캐시 / activation 을 타겟과 공유** → 드래프터가 컨텍스트 재계산 안 함

## 우리 프로젝트 적용

### moon1 (26B + 드래프터)

- 라이브 SoulX 아바타 응답 시간 **800ms → 270ms** 예상
- 진짜 실시간 대화 가능 → SoulX 영상 32 fps 와 동기화 자연스러움

### 폰 (E2B + 드래프터)

- E2B 자체 MTP: 임베더 클러스터링으로 logit 병목 가속
- 음성 인입→응답 지연 사용자 체감 < 200ms
